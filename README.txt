TRIPPLAN — ПЛАНИРОВЩИК ПУТЕШЕСТВИЙ

КАК ОТКРЫТЬ САЙТ
1. Распакуйте весь архив, а не отдельный файл.
2. Откройте папку site.
3. Откройте index.html в Chrome, Edge или другом современном браузере.
Все фотографии и шрифт находятся в папке проекта. Интернет для работы сайта не нужен.

Для запуска через локальный сервер (необязательно):
Откройте терминал в папке site и выполните:
python -m http.server 8080
Затем перейдите на http://localhost:8080

ЧТО ВНУТРИ
site/index.html — разметка основных разделов и форм.
site/html/about.html — инструкция для пользователя.
site/css/style.css — оформление, тёмная тема и адаптация под узкий экран.
site/js/data.js — список направлений и стандартных вещей.
site/js/app.js — переходы, обработка форм, расчёты и сохранение.
site/images — фотографии и значок сайта.
site/fonts — локальный шрифт Inter и его лицензия.
design — ссылка на редактируемый макет Figma и изображения семи экранов.
report — отчёт в Word и PDF, скриншоты работающего сайта.
TripPlan_defense.txt — короткий текст для защиты на троих.

ВОЗМОЖНОСТИ
- Поиск направлений и фильтры «Города» / «Природа».
- Добавление и удаление направлений из избранного.
- Создание, изменение и удаление поездок.
- Свой город или место, даты, бюджет и количество участников.
- Маршрут по дням: добавление, изменение и удаление мест и заметок.
- Расходы по категориям, сумма на человека и остаток бюджета.
- Список вещей: добавление, отметка готовности и удаление.
- Светлая и тёмная темы.
- Сохранение в браузере после обновления страницы.

ВАЖНО О ДАННЫХ
Это учебное приложение на HTML, CSS и JavaScript, без серверной базы данных.
Планы хранятся в localStorage: только в том же браузере и по тому же адресу.
Очистка данных браузера удаляет планы. Между устройствами они не синхронизируются.
После перемещения папки браузер может показать отдельное хранилище.
Если браузер блокирует сохранение, сайт показывает сообщение об этом.
Билеты и отели сайт не бронирует. Все расходы вводятся пользователем в рублях.

КАК ПОКАЗАТЬ ПРЕПОДАВАТЕЛЮ
Откройте «Мои поездки» → «Посмотреть пример Рима».
Покажите маршрут, бюджет и список вещей. Затем создайте свою поездку.
У примера стоит отметка «Пример»: его даты и суммы демонстрационные.
Покажите макет Figma, затем index.html, style.css, data.js и app.js.

МАКЕТ FIGMA
https://www.figma.com/design/Tv9SsZh5ehv5lDhImffnQO
Макет содержит редактируемые слои, компоненты и переходы между основными экранами.
PNG в папке design — копии экранов для просмотра. Исходный макет редактируется в Figma.

ТЕХНОЛОГИИ
HTML — содержание страниц и формы.
CSS — цвета, шрифты, расположение блоков и адаптивность.
JavaScript — действия пользователя и расчёты.
localStorage — хранение поездок, избранного и темы в браузере.
Основные разделы находятся в одном index.html и переключаются по адресу после #.
Это сохраняет единое хранилище при открытии сайта прямо из папки.

ПРОВЕРКА
В браузере проверены создание и изменение поездки, неправильный порядок дат,
добавление и изменение места, добавление и изменение расхода, превышение бюджета,
удаление тестовых записей, добавление и отметка вещи, поиск и избранное.
После перезагрузки поездка, расходы, отметки и избранное сохранились.
При ширине 337 CSS-пикселей проверены мобильное меню и раздел бюджета:
горизонтального переполнения страницы нет.
