# TripPlan — планировщик путешествий

Учебный сайт для планирования поездок. Позволяет составлять маршрут по дням, учитывать расходы и собирать список вещей.

## Возможности

- Поиск направлений и добавление в избранное.
- Создание, редактирование и удаление поездок.
- Выбор дат, количества путешественников и бюджета.
- Планирование маршрута по дням.
- Добавление мест, времени посещения и заметок.
- Учёт расходов по категориям.
- Расчёт остатка бюджета и расходов на человека.
- Список вещей с отметками о готовности.
- Светлая и тёмная темы.
- Адаптивное оформление для компьютеров и телефонов.

## Технологии

- HTML — структура сайта.
- CSS — оформление и адаптивность.
- JavaScript — работа кнопок, форм и расчётов.
- localStorage — сохранение данных в браузере.
- Figma — разработка макета.

## Структура проекта

Основные файлы находятся в папке site:

- index.html — основная страница.
- html/about.html — инструкция для пользователя.
- css/style.css — стили.
- js/data.js — данные направлений.
- js/app.js — логика сайта.
- images/ — фотографии и значок сайта.
- fonts/ — локальный шрифт.

## Как запустить

1. Скачайте проект: Code → Download ZIP.
2. Распакуйте архив.
3. Откройте файл site/index.html в браузере.

Установка дополнительных программ не требуется. Фотографии и шрифт включены в проект, поэтому сайт работает без интернета.

## Хранение данных

Поездки, избранное и выбранная тема сохраняются в localStorage. Данные доступны только в том браузере, где были созданы, и не синхронизируются между устройствами. При очистке данных браузера сохранённые планы удаляются.

Сайт является учебным проектом. Бронирование билетов, оплата и серверная база данных не предусмотрены.
